Frame TV setup

Every setting in config.properties, explained. Save, then build and install to send them to the TV. Everything is optional: an empty field uses the default.

What you change on the TV (the gear) wins over this file, until you change the same setting here: then the file wins once. Whatever was changed last applies.

The TV forgets its own changes if the app is uninstalled. This file is the backup: "Upload config" in the TV's gear sends them here while this page runs, and you accept them below.

Root on the TV

Turns off Samsung's tracking (ACR, ads, voice, analytics) and makes the remote's Home button open Frame TV, through temporary root: tools/root/root.sh, tested on a 2022 Frame. It needs tools/root/root.local.env. The TV's own values are kept on the TV the first time, so everything can be undone.

A restart (not standby) undoes step C, the four services that watch the network and report from the TV. "Apply everything" again puts it back and leaves the rest as it is.
